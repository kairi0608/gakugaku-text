# 教師・生徒フロー

## 教師

1. 管理者から `teacher` ロールを割り当ててもらいログインする。
2. `/teacher/classrooms` でクラスを作成し、8文字の参加コードを生徒へ伝える。
3. AI教材を生成する。生成直後は `draft` で、生徒には配布されない。
4. `/teacher/materials/[id]/review` で問題、正答、解説、画像、難易度を確認し、承認する。
5. `/teacher/assignments` で承認済み教材バージョンを選び、課題を公開する。公開すると教材は `published` になる。
6. `/teacher/special-events` では日時または連続ログイン条件のWhat Ifイベントを作成できる。
7. `/teacher/submissions` で自分のクラスの提出だけを確認し、得点とフィードバックを保存する。

## 生徒

1. `student` として登録しログインする。
2. `/student/assignments` で参加コードを入力する。
3. 公開済み課題を開く。課題は配布時の `material_version_id` に固定される。
4. GAME STARTから1問ずつ回答し、セット終了後にまとめフィードバックを確認する。
5. `/student/practice` では3 / 5 / 10問、興味、図鑑・イラストを選び、回答保存後に次の典型問題を生成する。
6. 特別イベントは通常問題と分けて表示され、自由な仮説を回答する。正誤得点ではなく参加EXPを付与する。
7. 履歴、EXP、キャラクター成長を確認する。

教師Aは教師Bのクラスや提出を参照できず、生徒Aは生徒Bの回答を参照できません。UIのリンク非表示だけでなく、APIガードとRLSの両方で制限します。
