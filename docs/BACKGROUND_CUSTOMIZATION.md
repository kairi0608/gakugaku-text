# 背景カスタマイズ

`/settings/appearance` で次を利用できます。

- 学習用途に限定したAI背景生成
- PNG / JPEG / WebPのアップロード
- 保存済み背景の選択、解除
- `cover / contain`、位置、オーバーレイ、ぼかしの調整

アップロードはMIME、10MB上限、デコード可否、320×240〜8000×8000の寸法を確認し、sharpでメタデータを除去してWebPへ再エンコードします。SVG、GIF、HTML、PDFは受け付けません。

背景はPrivate Storageに保存し、画面にはsigned URLだけを渡します。ヘッダーとカードは不透明度を高く保ち、背景オーバーレイは最低55%に制限して文字の読みやすさを確保します。
