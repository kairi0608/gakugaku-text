# ロールモデル

| ロール | 登録方法 | 主な権限 |
| --- | --- | --- |
| `personal` | 新規登録 | 自分の教材、学習、履歴、キャラクター、背景 |
| `student` | 新規登録 | 自分の自主学習、所属クラスの課題、自分の提出、キャラクター、背景 |
| `teacher` | 新規登録または管理者が割当 | 自分の教材、自分のクラス、課題、所属生徒の提出確認 |
| `admin` | 管理者が割当 | ユーザーのロール、全体統計、AI生成状態、システム設定状態 |

ロールの正本は `public.profiles.role` です。URL、クエリ文字列、フォーム値、クライアント状態は認可に使用しません。MiddlewareはUX上の早期リダイレクトを担当し、各ページとAPIもサーバー側で再確認します。最終的なデータ認可はRLSです。

生徒の `grade_band` は `elementary` / `middle` / `high` / `other` です。小学生は短い説明と大きな操作、中学生は標準密度、高校生は高密度の表示方針を共有データの上に適用します。
